### 해석 시 명시할 기술적 한계

- 입력 해상도 실험은 같은 파일의 디코드 뒤 resize이며 디코딩 해상도 자체를 바꾸지 않습니다. 녹화는 원본 크기입니다.
- drop_oldest는 독립 원본 보존 경로가 없어 비활성입니다. 분석 skip과 큐 drop을 혼동하지 않습니다.
- 카메라 내부 유실·블로킹 read, GUI, native codec 호환성은 실제 장치에서 검증해야 합니다.
- 파일 VFR은 PTS 지원을 확인해야 하며 고정 FPS 출력은 이전 프레임 유지 재표본화 한계가 있습니다.
- start_time/end_time은 관측치이며 실제 정답과 다를 수 있습니다. 미종료 사건 지속 시간을 임의로 채우지 않습니다.
- 정상 구간 수를 TN으로 가정하지 않습니다. 오경보율=오경보/전체 경보, 미검출률=미검출/정답 사건, 허용 오차 기본 0초입니다.
- 메모리 계측·종료 시 CSV는 강제 종료 내구성을 보장하지 않습니다. 긴 영상·다중 writer의 자원 사용량을 기록합니다.
